# 🧮 ManagX  
### *Smart Stock Management App*  

</div>

---

ManagX is a modern, clean, and efficient **Stock & Inventory Management App** built with **Jetpack Compose (MVVM Architecture)**.  
It helps shopkeepers and small businesses easily **manage, track, and analyze** their stock — all in one simple, beautiful interface.

---

## 🚀 Features

### 📦 Stock Management
- Add, edit, and delete products easily  
- Track total, low, and out-of-stock items  
- View real-time inventory levels  

### 📊 Analytics & Reports
- Daily in/out stock tracking  
- Generate summary reports  
- See trends in product performance  

### ⚙️ Smart Tools
- Quick search and filters  
- Product history tracking  
- Low-stock alerts  
- Data persistence with Proto DataStore  

### 🌙 Modern UI
- Built fully with Jetpack Compose  
- Material 3 theming (Dynamic color support)  
- Light/Dark mode toggle  

---

## 🧱 Tech Stack

| Layer | Technology |
|-------|-------------|
| **UI** | Jetpack Compose, Material 3 |
| **Architecture** | MVVM (ViewModel + State + Repository) |
| **Data Storage** | Proto DataStore |
| **Image Loading** | Coil |
| **Language** | Kotlin |
| **Build System** | Gradle (KTS) |
